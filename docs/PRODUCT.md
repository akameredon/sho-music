# Sho Music 2.0 — Product Contract

This repository implements the master PRD v2.0 and TRD v2.0 dated August 12, 2026.

## MVP Success Criteria (from PRD)

A user can:
- Create an account
- Import/upload permitted music
- Have it automatically analyzed and categorized by AI
- Search naturally
- Generate playlists
- Play music reliably (with rights checks)

AI classification pipeline operates automatically.  
Every protected asset has a traceable rights state.  
No single third-party music service is required for the core experience.  
Product works without special hardware.

## Non-Goals for MVP
- Worldwide major-label catalog on day one
- Custom smart speaker
- Global royalty infrastructure
- Social network / live / video platform
